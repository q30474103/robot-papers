# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable security issues in a public issue before a fix is available. Contact the repository owner privately through the security contact enabled on the hosting platform.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Do not include real API keys, private paper notes, unpublished manuscripts, or other personal data.

## Local data

Robot Papers is designed to read a user-selected local paper directory. Generated indexes, copied PDFs, notes, figures, logs, and `%APPDATA%\Robot Papers\config.json` are local runtime data and must not be committed to source control.
