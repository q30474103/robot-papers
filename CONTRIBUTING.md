# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Install dependencies with `pnpm install`.
3. Keep personal paper libraries, generated files, logs, installers, and API credentials outside commits.
4. Run `pnpm build:electron` before submitting a pull request.
5. Explain the user-visible change and include screenshots for interface changes.

Please keep pull requests small and avoid unrelated formatting changes.
